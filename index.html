How these triggers actually work on iOS

PhoneYaps uses Apple's native iOS frameworks to listen for events — no battery drain, no sketchy background tricks.

Battery

UIDevice delivers push notifications the moment the system detects a power source or charge level change. PhoneYaps registers a callback and reacts instantly.

WiFi

NWPathMonitor (Apple's Network framework) pushes an event when the network path changes — drops, reconnects, or switches between cellular and WiFi.

Bluetooth

CBCentralManager monitors nearby peripherals. PhoneYaps diffs the connected device set every few seconds to detect connects and disconnects without draining the radio.

Background

iOS limits background execution for non-system apps. PhoneYaps works best when open or recently backgrounded. If iOS suspends it, the app schedules a reminder notification so you can bring it back.

The result: minimal battery impact while the app is active, and honest about the limits iOS places on background apps.
